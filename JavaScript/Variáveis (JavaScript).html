Variáveis (JavaScript)

Em JavaScript, as variáveis servem para armazenar e manipular dados durante a execução do programa.

Para declarar variáveis em JavaScript, usa-se as palavras-chave const, let e var.

const

Variáveis do tipo const não podem ser redeclarados e nem reatribuídos:

JavaScript

const nome = "Ana";
nome = "Carlos";

A variável nome terá sempre o valor Ana, tentar reatribuir seu valor para Carlos resultará em erro.

let

Variáveis do tipo let não podem ser redeclarados, mas podem ser reatribuídos:

JavaScript

let nome = "Ana";
nome = "Carlos";

A variável nome terá o seu valor (Ana) reatribuído para Carlos.
