HTML

A Hypertext Markup Language (HTML), do inglês, Linguagem de Marcação de Hipertexto, é uma linguagem de marcação utilizada para a construção e estruturação de páginas da Internet (Webpages).

Para escrever em HTML, são usados os elementos, que por sua vez, são formados por tags (etiquetas).
