Sintaxe (HTML)

Em HTML, os documentos são escritos utilizando tags e elementos. Eles são essenciais para estruturá-lo de modo que fique legível ao navegador. Nós chamamos isso de sintaxe.

Elemento

Um elemento é uma parte do documento HTML que possui uma função especifíca. Dependendo do elemento, ele pode ser composto por:

  • Tag de abertura;
  • Atributos;
  • Conteúdo;
  • Tag de fechamento.

Elemento pareado

Um elemento pareado (paired element) é todo elemento HTML que possui uma tag de abertura quanto a tag de fechamento.

Elemento vazio

Um elemento vazio (void element) é todo elemento HTML que possui apenas a tag de abertura. Ou seja, não possui uma tag de fechamento (e nem conteúdo).

Tag de abertura

Uma tag de abertura é uma tag que declara o começo de um elemento (pareado ou vazio). Exemplos:

  • <p>;
  • <i>;
  • <h1>, <h2>, <h3>, <h4>, <h5> e <h6>;
  • <img>;
  • <br>;
  • <hr>.

Tag de fechamento

Uma tag de fechamento é uma tag que declara o fim de um elemento pareado. Exemplos:

  • </p>;
  • </i>;
  • </h1>, </h2>, </h3>, </h4>, </h5> e </h6>.

Conteúdo

O conteúdo é o texto que está entre as tags de abertura e fechamento. Exemplos:

  • <h1>Este é um título</h1>

    "Este é um título" é o conteúdo;

  • <p>Este é um parágrafo</p>

    "Este é um parágrafo" é o conteúdo;

  • <p><i>Este é um parágrafo, e o mesmo está em itálico</i></p>

    "Este é um parágrafo, e o mesmo está em itálico" é o conteúdo.

Atributos

Os atributos são informações extras inseridas na tag de abertura que modificam o comportamento do elemento. Exemplos:

  • <a href="https://exemplo.com">Visite o nosso site!</a>

    "href="https://exemplo.com"" é o atributo;

  • <img src="gato.jpg" alt="Um gato">

    "src="gato.jpg"" e "alt="Um gato"" são os atributos.

Os valores dos atributos podem ser colocados dentro de aspas simples (') ou aspas duplas (").

Estrutura básica

Documentos HTML possuem uma estrutura básica que deve ser seguida.

<!DOCTYPE>

<!DOCTYPE> é uma declaração (não uma tag) obrigatória, usada para informar ao navegador qual é o tipo de documento, neste caso, HTML:

  • <!DOCTYPE html>

    • "!DOCTYPE" é a declaração;

    • "html" é o tipo de documento.

<html>

As tags <html> e </html> definem a raiz do documento. Tudo que fizer parte do documento HTML, deve estar entre estas duas tags, ou seja, ser o conteúdo:

HTML

<!DOCTYPE html>
<html>

</html>

<head>

As tags <head> e </head> definem o cabeçalho dodocumento (conteúdo que não é mostrado na página). Os metadados e informações adicionais devem estar entre estas duas tags, ou seja, ser o conteúdo delas:

HTML

<!DOCTYPE html>
<html>
<head>

</head>
</html>

<title>

As tags <title> e </title> definem o título do documento que aparece na aba do navegador. Elas devem estar entre as tags <head> e </head>. Exemplo:

HTML

<!DOCTYPE html>
<html>
<head>
<title>Título de Exemplo</title>
</head>
</html>

<body>

As tags <body> e </body> definem o corpo do documento (conteúdo que é mostrado na página). Os títulos, subtítulos, parágrafos, imagens, hyperlinks etc. devem estar entre estas duas tags, ou seja, ser o conteúdo delas:

HTML

<!DOCTYPE html>
<html>
<head>
<title>Título de Exemplo</title>
</head>
<body>
<p>Este é um parágrafo.</p>
</body>
</html>
